# 👑 허니스윗팜 비서실 — 클라우드(웹) 버전

PC·휴대폰 어디서든 브라우저로 여는 **비서실** 화면입니다. 서버가 필요 없습니다(GitHub Pages 정적 호스팅).

- 회의실(대회의실·지휘실·라운지) — 지시·메모, 이름을 부르면 **접수 확인**이 붙습니다.
- 작업실 — 주문함 현황(신규결제·배송준비·미매칭), 정기 스케줄, 할 일.
- 비서현황 — 사장님·허팜이(대장)·경진2(부대장) 담당과 정기 스케줄.
- 메모 — 빠른 메모, 수정·삭제.

## 쓰는 법

1. 주소를 엽니다 (예: `https://kyoungkk79-dev.github.io/heofarm-office/`).
2. 휴대폰은 브라우저 메뉴의 **홈 화면에 추가**를 눌러 두면 앱처럼 열립니다.

## 저장 방식 — 중요

- 이 화면의 내용은 **그 브라우저의 localStorage** 에만 저장됩니다. 서버로 보내지 않습니다.
- 그래서 **기기마다 내용이 따로** 저장됩니다. 기기를 바꾸거나 PC/휴대폰 내용을 맞추려면
  **메모 → 내보내기(JSON)** 로 파일을 받아 다른 기기에서 **가져오기** 하세요.
- 브라우저 데이터를 지우면(인터넷 기록 삭제 등) 비서실 내용도 함께 지워집니다. 중요한 내용은 내보내 두세요.
- PC 주문함 프로그램의 비서실(`command_center_state.json`)과는 별도입니다.
  PC의 `비서실 → ⬇ 내보내기(JSON)` 파일을 이 화면의 **가져오기**로 열면 대화·할 일·메모·주문 요약을 함께 가져옵니다.

## 주문 현황

- **설정 → 직접 입력**: 신규결제·배송준비·미매칭 건수를 적어 두면 작업실 카드에 표시됩니다(마지막 입력 시각 함께 저장).
- **설정 → 허팜 API 주소·키**: 넣어 두면 ‘지금 허팜에서 가져오기’로 주문을 읽어 집계합니다.
  다만 브라우저 보안 정책(CORS) 때문에 허팜 서버가 브라우저 호출을 허용하지 않으면 막힙니다.
  그때는 PC 주문함에서 내보낸 파일을 쓰거나 직접 입력하세요.
- API 키는 **이 브라우저에만** 저장되고 코드에는 들어 있지 않습니다.

## 보안

- 이 저장소에는 API 키·전화번호·주소·비밀번호가 들어 있지 않습니다.
- 입력한 내용은 브라우저 밖으로 나가지 않습니다(외부 전송 코드 없음).
- 누구나 이 페이지를 열 수는 있지만, 각자 자기 브라우저에만 저장되므로 남의 내용은 보이지 않습니다.
- 검색엔진에는 걸리지 않게 했습니다 — `index.html` 의 `<meta name="robots" content="noindex, nofollow">` 와 루트의 `robots.txt`(`User-agent: *` / `Disallow: /`).
- 주소를 아는 사람만 열 수 있으니, 링크는 필요한 사람에게만 보내 주세요.

## 고치기

`index.html` 한 파일이 전부입니다(스타일·스크립트 포함). 고쳐서 `main` 브랜치에 올리면 1분 안에 반영됩니다.

```bash
git clone https://github.com/kyoungkk79-dev/heofarm-office.git
# index.html 수정
git commit -am "비서실 문구 수정" && git push
```
