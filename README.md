# 👑 허니스윗팜 비서실 — 클라우드(웹) 버전

PC·휴대폰 어디서든 브라우저로 여는 **비서실** 화면입니다. 서버가 필요 없습니다(GitHub Pages 정적 호스팅).

- 회의실(대회의실·지휘실·라운지) — 지시·메모, 이름을 부르면 **접수 확인**이 붙습니다.
- 작업실 — 주문함 현황(신규결제·배송준비·미매칭), 정기 스케줄, 할 일.
- 비서현황 — 사장님·허팜이(대장)·경진2(부대장) 담당과 정기 스케줄.
- 메모 — 빠른 메모, 수정·삭제.

## 쓰는 법

1. 주소를 엽니다 (예: `https://kyoungkk79-dev.github.io/heofarm-office/`).
2. 휴대폰은 브라우저 메뉴의 **홈 화면에 추가**를 눌러 두면 앱처럼 열립니다.

## 저장 방식 — 중요

- 대화·할 일·메모는 **Firebase Realtime Database**(무료 Spark 플랜)에 저장됩니다.
  - 프로젝트 `heofarm-office` · 리전 싱가포르(asia-southeast1)
  - 화면은 **3초마다** DB를 확인해 PC·휴대폰이 같은 내용을 봅니다(새로고침 불필요).
  - 이 브라우저에도 사본을 남겨 두어, 인터넷이 끊겨도 읽고 쓸 수 있고 연결되면 자동으로 다시 보냅니다.
- 사장님이 지시를 보내면 **허팜이(대장)가 5분 안에 확인해 실제 답변**을 남깁니다(가짜 '자동 접수' 문구 없음).
- PC 주문함 프로그램이 켜져 있으면 주문 현황(신규결제·배송준비·미매칭·발주대기·발송중)이 자동으로 이 화면의 **작업실** 카드에 들어옵니다.
- **내보내기(JSON)** 는 백업용입니다.

## 주문 현황

- PC 주문함이 켜져 있으면 자동으로 채워집니다.
- **설정 → 직접 입력**: 신규결제·배송준비·미매칭 건수를 적어 두면 작업실 카드에 표시됩니다.
- **설정 → 허팜 API 주소·키**: ‘지금 허팜에서 가져오기’로도 읽을 수 있습니다(CORS 허용 시). 키는 이 브라우저에만 저장됩니다.

## 보안 (꼭 읽어 주세요)

- DB는 주소 전체가 열려 있지 않습니다. 루트는 차단되고 **비공개 키 경로(`/office/<키>`)만** 읽기/쓰기가 허용됩니다(규칙 게시됨).
- 다만 이 페이지는 **공개 주소**이고 그 키가 페이지 소스에 들어 있습니다. 주소를 아는 사람이 소스를 열면 그 경로의 대화를 읽거나 쓸 수 있습니다.
  그래서 **주민번호·계좌 비밀번호·카드번호 같은 민감정보는 이 화면에 쓰지 마세요.** 링크도 필요한 사람에게만 보내 주세요.
- 검색엔진에는 걸리지 않게 했습니다 — `index.html` 의 `<meta name="robots" content="noindex, nofollow">` 와 루트의 `robots.txt`(`User-agent: *` / `Disallow: /`).
- 더 막고 싶으면 Firebase 인증(이메일 로그인) + 규칙 `auth != null`로 올리는 방법이 있습니다. 지금은 앱처럼 바로 열리도록 인증 없이 두었습니다.

## 고치기

`index.html` 한 파일이 전부입니다(스타일·스크립트 포함). 고쳐서 `main` 브랜치에 올리면 1분 안에 반영됩니다.

```bash
git clone https://github.com/kyoungkk79-dev/heofarm-office.git
# index.html 수정
git commit -am "비서실 문구 수정" && git push
```
